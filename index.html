Install kaise kare? (Safety guide)
  1. APK Download dabao. Browser warning de ("ye file harmful ho sakti hai") to Download anyway / Keep dabao — Chrome har APK par ye dikhata hai.
  2. Download hui file kholo. "Install unknown apps" aaye to Settings kholo, apne browser (Chrome) ke liye Allow from this source ON karo, phir back aao.
  3. Play Protect "App blocked / scan" dikhaye to More details → Install anyway dabao. App sirf internet use karta hai, koi personal permission nahi maangta.
  4. Install hone ke baad Open karo. Safety ke liye Settings me wo Allow from this source wapas OFF kar do.
  5. Naya version aane par app khud "Update karo" dikhayega. Study content ke liye update ki zaroorat nahi, wo automatic hai.
⚠ APK sirf isi website se download karo. WhatsApp / Telegram par kisi ne bheji APK install mat karo. "App not installed" aaye to purana version uninstall karke dobara install karo.
